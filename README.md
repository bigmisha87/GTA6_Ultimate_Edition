# GTA VI Ultimate Edition - מדריך אינטראקטיבי

פתיחה: חלץ את קובץ ה-ZIP ופתח את index.html בדפדפן.

העמוד כולל רשימת פריטים, חיפוש, סינון וסימון התקדמות.

חשוב: התמונות נטענות מכתובות חיצוניות (PC Gamer CDN) ולא כלולות בחבילה. לכן הצגתן דורשת חיבור אינטרנט ושהשרת המקורי יאפשר טעינה.

הפרויקט הוא קובץ HTML יחיד עם CSS ו-JavaScript מובנים.

## קרב מגע (combat.html)

עמוד עם כל 63 מהלכי הקרב מגע של ג׳ייסון ולוסיה: כפתורי PlayStation ו-Xbox, הדגמה מונפשת לכל מהלך, סינון לפי פרק ודמות, וסימון "למדתי".

הצילומים בתיקייה `combat-assets` נלקחו מהסרטון Everything About Fighting In GTA 6 של הערוץ Gemzy GTA (24.11.2026), וכל מהלך מקשר לרגע שלו בסרטון. הם שמורים מקומית ועובדים גם בלי אינטרנט.

לכל מהלך יש גם קטע וידאו קצר בלי סאונד (עד 6 שניות), בתיקייה `combat-assets/clips`. כפתור "הדגמה" מנגן אותו במקום התמונה, יחד עם הדלקת הכפתורים. הקטעים נחתכו מאותו סרטון ועובדים גם בלי אינטרנט.
